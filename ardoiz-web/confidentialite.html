Politique de confidentialité

Ce document décrit ce que fait réellement l'application Carné de vos données.

Version de travail. Les passages entre crochets [à compléter] dépendent d'informations que seul l'éditeur peut fournir (identité, hébergeur, contact). Ce texte doit être relu par un juriste avant la mise en service publique.

1. Qui est responsable

Éditeur du service : [à compléter : nom ou raison sociale, adresse, pays]. Contact pour toute question sur vos données : [à compléter : adresse e-mail].

2. Les données traitées

DonnéeÀ quoi elle sert
Votre numéro de téléphoneCréer et protéger votre compte, vous envoyer le code de vérification par SMS.
Le nom de votre boutiqueVous identifier et signer les messages de relance envoyés à vos clients.
Votre code PINVous connecter. Il n'est jamais conservé en clair : seule une empreinte irréversible est enregistrée.
Vos clients : nom, numéro de téléphone, plafond de crédit éventuelTenir votre carnet et leur envoyer des relances que vous avez décidées.
Vos dettes et remboursements : montants, motifs, catégories, datesCalculer les soldes, les retards et votre tableau de bord.
L'historique des relances envoyéesNe pas relancer deux fois la même étape pour une même dette.

Carné ne lit pas vos contacts, ne demande pas votre position et ne contient ni publicité ni outil de suivi publicitaire.

3. Vos clients

Les noms et numéros de vos clients sont des données personnelles dont vous décidez l'usage : vous êtes responsable de leur collecte auprès d'eux. Carné les traite uniquement pour votre compte, afin de faire fonctionner votre carnet et d'envoyer les relances que vous demandez ou que vous avez programmées.

4. Où sont stockées les données

  • Sur votre téléphone : dans une base chiffrée (AES-256). La clé de chiffrement est conservée dans le coffre sécurisé du téléphone. Les sauvegardes automatiques Android sont désactivées pour ces données.
  • Sur nos serveurs : dans une base de données, pour retrouver vos données si vous changez de téléphone et pour envoyer les relances. Hébergeur et pays : [à compléter].
  • Les échanges entre l'application et le serveur passent par une connexion chiffrée (HTTPS).

5. Prestataires

  • Envoi de SMS (codes de vérification et relances) : un opérateur d'envoi de SMS, qui reçoit le numéro du destinataire et le texte du message. Prestataire prévu : Africa's Talking [à confirmer].
  • Paiement Mobile Money : le paiement de l'abonnement et les demandes de paiement ne sont pas encore ouverts. Le prestataire sera nommé ici avant l'ouverture : [à compléter].

Aucune donnée n'est vendue.

6. Combien de temps

Vos données sont conservées tant que votre compte existe. Elles sont supprimées quand vous supprimez votre compte. Durée de conservation des journaux techniques du serveur : [à compléter].

7. Vos droits et la suppression du compte

  • Accès et copie : dans l'application, Réglages, « Exporter l'historique » produit un fichier CSV de vos données.
  • Correction : vous pouvez modifier à tout moment vos clients, vos dettes, vos remboursements et le nom de votre boutique.
  • Suppression : dans l'application, Réglages, « Supprimer mon compte » (confirmé par votre code PIN) efface définitivement votre compte, vos clients, vos dettes, vos remboursements et vos relances sur nos serveurs, ainsi que les données de ce téléphone. Cette action est irréversible.
  • Pour toute autre demande : [à compléter : adresse e-mail].

8. Sécurité

Le code PIN est protégé contre les essais répétés (verrouillage temporaire après 5 erreurs). Une session fermée ou un changement de code PIN rend immédiatement inutilisables les sessions précédentes. Aucun système n'est infaillible : gardez votre code PIN secret et verrouillez votre téléphone.

9. Modifications

En cas de changement important, cette page sera mise à jour et la date ci-dessous modifiée. Dernière mise à jour : [à compléter à la publication].
